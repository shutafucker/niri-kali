# Niri + Noctalia Configs & Kali Linux Installer

## 🚀 Как развернуть на Kali Linux

```bash
git clone <URL_ВАШЕГО_ПРИВАТНОГО_РЕПОЗИТОРИЯ>
cd dotfiles-niri-kali
chmod +x install.sh
./install.sh
```

После завершения выйдите из текущей сессии (Log Out) и на экране входа (LightDM/GDM) выберите **Niri**.
